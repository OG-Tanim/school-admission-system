# School Admission System

Monorepo for the Onnorokom Projukti school admission assignment: an ASP.NET Core
minimal API, PostgreSQL, and a React UI, all runnable with Docker Compose.

## Run with Docker

```bash
docker compose up --build
```

| Service | URL |
|---|---|
| Frontend | <http://localhost:3000> |
| Backend API | <http://localhost:8080> |
| API health check | <http://localhost:8080/health> |

The API applies the EF Core migrations on startup, after waiting for PostgreSQL to
accept connections. Optional overrides can be placed in a root `.env` file (copy
`.env.example`): `API_URL`, `HOLD_DURATION_SECONDS`, and the `POSTGRES_*` credentials.

### Data persistence

PostgreSQL stores its files in the named volume `postgres_data`, so classes, holds,
and confirmed admissions survive container restarts and `docker compose down` followed
by `docker compose up`.

`docker compose down -v` deletes the volume and therefore the data — use it only when
you want an empty database.

### Changing the backend URL

The UI never hard-codes the backend. It reads the URL at runtime in this order:

1. the value chosen in the **Backend URL** field on the page (stored in `localStorage`,
   applied immediately, no reload or restart — useful when several backends run
   against the same UI);
2. `/config.js`, generated by the frontend container from the `API_URL` environment
   variable when the container starts;
3. `http://localhost:8080` as the final fallback.

`API_URL` can be changed without rebuilding the image:

```bash
API_URL=http://localhost:8081 docker compose up -d frontend
```

The **Reset to default** button clears the browser override and falls back to
whatever the server is configured with.

## Run without Docker

Backend (needs a reachable PostgreSQL and the .NET 10 SDK):

```bash
cd backend
dotnet restore
dotnet ef database update
dotnet run                  # http://localhost:8080
```

Override the connection with `ConnectionStrings__DefaultConnection`
(`Database__MigrateOnStartup=false` skips startup migrations).

Frontend (Node.js 20.19+ or 22.12+):

```bash
cd frontend
npm install
npm run dev                 # http://localhost:5173
```

In development the API URL comes from `frontend/public/config.js`, or from the
**Backend URL** field in the UI.

## Tests

```bash
dotnet test backend/tests/SchoolAdmission.Api.Tests.csproj
```

The tests start a disposable PostgreSQL 16 container with Testcontainers, apply the
real EF Core migrations, and call the API. Docker must be running. See
[test.md](backend/test.md) for endpoint-by-endpoint coverage.
